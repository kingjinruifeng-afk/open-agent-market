# 运营、资源与试点（Skill 与仓库共享说明）

## 谁运营公共节点

代码维护者并不自动承担公共节点。初期项目方可提供有额度、期限和明确服务条款的参考节点；同时招募至少一个独立 Agent 宿主或商家工具服务商运营备份/索引。真实独立运营者各自承担主机、备份、安全、账单与数据合同。

长期收入可来自容量、检索预算、领域索引、存档和托管费。公开商品/证据可迁移；不能付费提高评价或购买有利判责。志愿者节点不作为商业可用性保证。商业运营协议、第三方收费与真实成本应在试点中验证。

多节点开放网络已有可借鉴实践：Nostr 中继、Matrix 自托管/商业托管、Mastodon 联邦服务器。交易方面 Beckn/ONDC 提供网络治理参考。它们分别解决部分网络/运营问题，不证明本项目的交易信誉或市场认可；来源见 REVIEW.md。GitHub 用于维护和分发代码，不承担交易网络数据库。

## 本地节点配置

| 变量 | 默认/用途 |
|---|---|
| OAMP_KEY_FILE | .data/operator.key.json；先运行keygen |
| OAMP_SELLER_KEY_FILE | 未配置；需要提供卖方在线证明时指定当前卖方控制键 |
| OAMP_SELLER_PRINCIPAL | 未配置则使用卖方键ID；轮换后指定持久主体根ID |
| OAMP_DB | .data/node.sqlite |
| OAMP_HOST / OAMP_PORT | 127.0.0.1 / 8787 |
| OAMP_PUBLIC_ORIGIN | 未配置；反向代理后提供签名证明中的公开origin |
| OAMP_ADMIN_TOKEN | 未配置则同步管理API禁用；使用本机生成的长随机令牌 |
| OAMP_MAX_EVENTS | 10000；含身份、程序、历史事件 |
| OAMP_PROOF_TTL_MS | 10000；超过10秒仍截断，测试可缩短 |
| OAMP_SELLER_ORIGINS | JSON origin数组；只探测明确允许的卖方来源 |
| OAMP_PEERS | JSON数组，每项url/publicKey，固定已信任运营者 |
| OAMP_NAME | reference-node |

私钥存在本机 `.data`，公共事件不包含私钥。CLI 生成文件拒绝覆盖。生产应由宿主保险库提供签名代理，Windows 主机另设 ACL。Seller principal 轮换后通过配置指定持久根ID。

同步公开事件示例：

```powershell
$env:OAMP_PEERS = '[{"url":"https://trusted-node.example","publicKey":"已验证的base64公钥"}]'
$env:OAMP_SELLER_ORIGINS = '["https://authorized-seller.example"]'
# 启动后用自己的令牌 POST /v1/sync，body={"source":"https://trusted-node.example"}
```

同步不是自动循环服务。宿主/运营者在预算内安排增量拉取；一条接受回执仅证明当前节点存储。商业发布应配置两个有合同的存档并检查各自接受凭证。

## 成本控制

卖家 Skill 优先复用已授权的官网参数、CDN图文或既有店铺详情，把型号、价格、条件、签名版本、联系origin等必要字段留在网络。引用外部页面不能绕过其访问限制，不能证明本卖家的真品、库存、售后或历史好评；资源不可达时保留最小本地知识或提供已授权镜像。

静态参数/FAQ不用模型。模型只处理少量候选的个性化问题，宿主应设置请求并发、每轮字数/Token预算、超时、冷却、缓存和人工转接；不因“持续在线”默认允许无限模型调用。参考服务没有模型自动调用。

公共索引承担检索CPU/内存，买方按页拉取摘要并逐步补充详情；不在个人 Agent 内下载全网商品或固定探测全网卖家。短期在线证明共享，重复并发查询合并为一个探测；卖家在线检测成本主要来自选择它的索引节点数量和证明刷新频率，而非每次买方查询都触发模型。

## 无既有渠道时如何估算资源

必须先在目标部署测量结构化请求CPU时间、返回大小、热缓存/冷缓存、索引常驻内存，以及少量模型调用的实际时延/消耗。以下为可代入的预算公式，不能用本机一次基准直接宣称支持多少用户：

- CPU核数下界 = 请求/秒 × 每请求CPU毫秒 ÷ 1000 ÷ 目标利用率；再为签名/存储/峰值预留资源。
- 出站带宽Mbps = 请求/秒 × 平均响应字节 × 8 ÷ 1,000,000；再计算资源缓存命中与媒体出站。
- 月度出站GB ≈ 平均请求/秒 × 响应字节 × 实际服务秒数 ÷ 1,000,000,000。
- 并发请求内存 = 同时执行请求数 × 每请求工作区 + 常驻索引/缓存/运行时；RSS不能简单线性按用户增长。
- 模型并发量 ≈ 请求/秒 × 模型触发比例 × 模型平均秒数；Token/秒 ≈ 请求/秒 × 触发比例 × 每次Token数。GPU型号和显存须按模型实测。
- 档案容量 = 平均日事件数 × 平均事件字节 × 保留天数 × 复制份数，再加索引和备份；多份复制由不同运营者付费维护。

`npm run capacity -- --rps 20 --cpu-ms 2 --response-bytes 16000 --model-share 0.1 --model-seconds 2 --tokens 300` 提供**基于输入假设**的预算，不是测量值。未输入索引和工作区参数时不猜内存/GPU。

`npm run benchmark` 生成本机实测原始报告。默认500个商品/1个卖家/40次查询/1个并发买方；两个服务共享一个进程。搜索当前扫描JSON投影，无法外推到海量商品。模型、WAN、多卖家、恶意流量与真实付款均未测。

## 容器

`Dockerfile` 为本地/测试封装，当前主机无Docker，尚未进行容器运行验证。先在主机keygen，再把 `.data` 以正确文件权限挂载。镜像中的非root node用户需对数据卷可写；宿主监听/端口映射和 publicOrigin 必须相符。

```text
docker build -t open-agent-market-reference .
docker run --rm -p 127.0.0.1:8787:8787 -v ABSOLUTE_DATA_PATH:/app/.data -e OAMP_HOST=0.0.0.0 open-agent-market-reference
```

不要直接公网暴露开发HTTP服务器。公网前先部署 TLS、入口身份/网络预算、备份恢复、动态来源审核、防SSRF/DDoS和隐私保留策略；这些是 Gate B 运营验收条件。

## 真实试点证据

至少两名现实独立运营者记录服务承诺、恢复演练和真实账单。两种宿主适配路径记录API调用和预算；商家/买家自愿参加真实场景；评审人员具有专业能力与关系披露。每个样本保留来源/时间/版本、签名与隐私授权，分别标注交易声明和可外部核验事实。

试点须报告：供给发布成本、有效召回和价格时效、询价成功率、模型触发比例、迁移故障、普通维权误伤、评价可迁移性、串谋攻击、费用接受度、实际争议及复审结果。没有真实争议时不得把模拟评审计为真实纠纷样本。

没有可证明的独立评审人数时返回不足并转入当事人现有售后/争议渠道；不得临时生成匿名身份凑人数。

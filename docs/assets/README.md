# Visual assets

These images explain Open Agent Market's direction. They are conceptual illustrations, not screenshots, participant counts, endorsements or evidence of a production network.

- `open-market-vision.png`: personal agents discovering independent shops and services across an open network.
- `bilateral-trust.png`: persistent buyer/seller identities, bilateral evidence and an appealable community-review aspiration.
- `agent-flow.svg`: an editable, static protocol-flow diagram. No external fonts, scripts or linked resources.

The two PNG illustrations were generated with the built-in image generation tool on 2026-10-11, inspected, and copied into this repository. The SVG was authored directly for deterministic labels. Text descriptions accompany the images in both READMEs for accessibility and localization.

## Generation prompts

### hero

Use case: illustration-story. Asset type: a wide GitHub README hero, landscape 16:9. Create an inviting, clever editorial illustration for the open-source project Open Agent Market: personal AI agents discovering goods and services directly across a federated open network. Scene: a charming miniature neighborhood of independent shops and service studios, each with its own friendly small robot assistant. One buyer robot carries a shopping brief; shop robots hold simple signed product cards and knowledge books. Several equal small relay islands and dotted paths connect participants peer-to-peer, with no giant central building and no single dominant server. Show open doors, curiosity, and useful exchanges of information; restrained whimsy, tactile paper-cut shapes and crisp ink outlines, warm ivory background, deep navy, teal and small coral accents. Composition: generous clean space in the upper left for a large legible title, tiny architectural storytelling below and right, very readable at 900px width. Include exactly this English text in clean typography: "OPEN AGENT MARKET" and under it "Your agent. An open market." Nothing else written in the image. Communicate openness and independent ownership, not a blockchain or cryptocurrency project. Avoid coins, tokens, chains, corporate logos, endorsements, fake statistics, badges implying verified trade, photoreal people, hologram clutter, generic neon sci-fi. This is a vision illustration, not a screenshot of an existing production marketplace.

### trust

Use case: illustration-story. Asset type: landscape 16:9 editorial illustration for a GitHub README section on bilateral trust. Make a warm, whimsical but mature illustration in crisp ink outlines with tactile paper-cut shapes, ivory background, navy and teal with restrained coral accents. Scene: two friendly little AI robots, one buyer and one seller, sit at opposite sides of a modest worktable. Each has its own portable open history notebook with dated simple marks (no readable words), a little personal key and a folder of evidence. Between them, two equal arrows form a balanced loop of feedback, emphasizing that BOTH sides build long-term reputations. Nearby three small independent reviewer robots examine sealed evidence folders under a desk lamp; a gentle return arrow suggests an appeal and correction, no judgment hammer or punishment aesthetic. Keep distinct buyers, sellers and reviewers visually understandable without crowded labels. Include exactly these large clean English labels: "TRUST GOES BOTH WAYS" and a smaller line "Keep your identity. Earn your reputation." No star ratings, scores, verified stamps, money, crypto tokens, national identity cards, platform logos, or claims of guaranteed safety. Rich human-readable visual metaphor, strong negative space, legible at 850px width. It depicts an aspiration and evidence review, not proof of real users or resolved real disputes.

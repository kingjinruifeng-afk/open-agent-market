# 架构复审 · 2026-10-11

审查依据：本轮完整讨论、当前空工作区及官方协议资料。不是已经运行的生产网络评测。

## 必须修正

1. **协议与运营混淆**：GitHub 提供代码不提供公共服务。新增节点服务声明、预算、容量上限、存档期限、导出和独立运营 Gate。
2. **评分证据不明确**：签名不证明交易真实。双方声明、客观事件、外部证明分开；首版不将自报事件包装为已验证履约率，不输出强制总分。
3. **匿名评审资格与随机性**：高交易分不能证明独立性或专业能力。参考实现使用明确配置的试点评审池，公开选择依据；它不等于抗女巫、不可操纵的公共陪审团。
4. **惩罚与正常维权**：退货、退款、差评、败诉均不是恶意证据。只有有理由且经过程序的诚信结论能改变对应标签，申诉期间不生效。
5. **全部数据广播不可扩展**：卖方维护权威商品，订阅范围内复制摘要和证据；不强迫个人 Agent 保存全网数据。
6. **在线检查成本与 SSRF**：取消全网固定双节点高频探测。共享短期结果、合并请求、只探测明确允许的来源；不跟随任意商品 URL 发起请求。
7. **跨节点一致性**：迁移必须携带依赖事件；有冲突拒绝写入并返回诊断，后续需补隔离与解决策略，不以本地接收顺序判定全球真相。
8. **私密与公开混合**：议价以加盐承诺关联，公开事件使用允许字段列表。私密材料加密自存，不接受完整地址/对话进入公开事件。
9. **交易承诺与库存**：报价不是库存预留。参考版本只记录双方约定，不声称解决外部库存并发或款项执行。
10. **维护面过大**：先以单一 TypeScript 节点复用逻辑角色，配 Python 客户端、SDK、宿主 Skill；PostgreSQL、大文件镜像、支付证明生产接入列为下一阶段。

## 保留的技术/商业判断

个人 Agent 的开放供给与可迁移信誉值得验证，但不能从类似协议存在推断市场需求已成立。Nostr 的多中继、Matrix 的商业托管、Beckn/ONDC 的交易治理分别是参考，均不能替代本项目的真实验证。

## 审查结论

允许执行 Gate A：可运行、可重放、可复制的实验参考网络。禁止宣称已完成 Gate B：独立运营、真实用户与反串通验证。不能以模拟 8 个评审身份冒充 8 个独立第三方。

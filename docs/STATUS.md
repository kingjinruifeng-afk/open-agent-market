## 复审后修复的具体问题

1. Windows Python系统编码使中文事件哈希不一致：互通进程强制UTF-8，加入固定公开向量。
2. 在线证明到期边界因网络毫秒差拒绝有效卖家：容许小幅时钟偏差，缓存仍严格限制最长10秒，加入活跃结果断言。
3. 空过滤结果错误提示后续页面：hasMore基于同一过滤集合，不再引导无效分页。
4. 身份轮换后的旧在线缓存：缓存核对当前控制键，轮换后重新探测。
5. 评价修订可能重复样本：按原评价版本替换投影，保存旧签名历史。
6. 不同责任多数和诚信多数可能拼接严重标签：严重标签必须由支持同一责任结论的多数签署。
7. 无界知识、远端读取和缓存：知识限制24KB，远端JSON响应按类型限额，来源桶及在线缓存限额1000，同来源同步请求合并。
8. 迁移分叉：拒绝冲突、不覆盖本地版本；未实现自动解决或全局一致性。
